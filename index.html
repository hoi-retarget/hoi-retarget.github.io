HOI-Retarget:
Contact-Centric Retargeting for Human-Object Interaction

Transferring human-object interaction onto humanoid robots while preserving where and when the object is touched.

Abstract

Imitating retargeted human motion with reinforcement learning (RL) is a dominant recipe for teaching humanoid robots whole-body skills, but it is data-hungry and largely confined to object-free motion. Retargeting human-object interaction (HOI) is markedly harder: the pipeline must bridge the human-robot embodiment gap while keeping the interaction intact, and existing methods preserve the overall spatial arrangement of the scene without reproducing where the human actually touched the object.

We present HOI-Retarget, a contact-centric retargeting method that transfers HOI onto a humanoid robot for large-scale motion-data generation. Every labeled contact is expressed as a target in the object frame and recovered by a windowed trajectory optimization that balances it against body tracking, foot support and smoothness under the robot's kinematic limits. Because the contacts are anchored to the object, the same formulation rescales objects to the robot's embodiment, augments a single demonstration across object sizes, absorbs contacts reconstructed from monocular video, and extends to several robots manipulating one object.

Across 13 object categories of OMOMO retargeted to a Unitree G1, HOI-Retarget reduces the contact-point gap of the state-of-the-art interaction-aware retargeter from 18.3 to 0.5 cm at less than a quarter of the compute, and the advantage persists after the references are made dynamically feasible by both an RL tracker and a sampling-based trajectory optimizer. We release the pipeline together with 6,964 retargeted humanoid interaction clips, spanning 75 object categories and 13.8 hours.

Method

How it works

Body pose alone is not enough. Because humans and humanoids differ in proportions, joint structure and reach, matching poses independently can slide a hand off the object, move it to a functionally different surface, or push it through the mesh. HOI-Retarget instead optimizes directly against the contact the human made.

Contacts as object-frame targets

Every labeled contact is expressed as a target in the object frame rather than in the world. The optimization drives the robot's palm to that point, so the grasp lands on the surface the human actually used — and it re-anchors automatically when the object is rescaled.

Overlapping-window optimization

Body tracking, contact alignment, foot support and smoothness are balanced under the robot's joint-position and velocity limits. Overlapping windows couple consecutive frames while keeping memory bounded, so long clips stay tractable.

Correcting noisy contacts

Contact annotations recovered from monocular video are frequently wrong. An optional interactive tool lets the target location and time interval of each contact segment be corrected before the optimization runs.

Results

Diverse objects and embodiments

OMOMO retargeted onto the Unitree G1 and H2, covering 13 object categories from small boxes to tables, chairs and floor lamps. Only the robot model and the contact-link map change between embodiments — the annotation, the contact targets and the cost set are identical.

Generality

Beyond a single dataset

The same pipeline runs on other HOI sources without modification; four of them join OMOMO in the released corpus. Multi-robot collaboration needs no extra machinery: because every contact target lives in the object's frame and the object trajectory is a fixed input, each human is retargeted independently against the same object motion and the resulting robot trajectories stay mutually consistent by virtue of that shared trajectory alone. A world-frame formulation would have to couple the solves explicitly.

Comparison

Against OmniRetarget

Interaction-aware retargeting preserves the overall body-object geometry, but does not minimize the error to each individual source contact. On objects with thin or spatially localized grasp regions the hand ends up somewhere the human never touched. Neither baseline resizes objects, so object mesh scaling is disabled for this comparison: every method manipulates an identically sized object, and only the object trajectory is brought into the robot's reach.

Data generation

Object-scale augmentation

One captured motion becomes many. Because the contact targets live in the object frame, resizing the object carries them with its surface, so the same clip can be re-solved at any object size without re-annotating the interaction. Sweeping the multiplier from ×0.25 to ×1.50 turns one demonstration into a family of interactions with objects the human never handled, each grasped at the locations of the original.

In the wild

From monocular video

To test a source outside dedicated capture, we record a monocular video of a subject moving a table that appears in no dataset, and reconstruct the human mesh, the object mesh and their trajectories. Reconstructed contacts are far noisier than motion capture — occlusion and depth ambiguity leave the hand alternating between penetrating the table and floating above it, and retargeting such labels directly produces contact targets that jitter across the object surface. Collapsing each contact segment to a single point and correcting the remaining outliers removes this failure mode, and yields a clean robot interaction from one hand-held video.

Downstream

Dynamic refinement

A kinematic retarget is not yet physically feasible, and the pipelines that consume it differ in how they repair that. We ask whether the advantage above survives, using two refiners of different families on the same references: a per-clip RL tracker trained with DeepMimic-style rewards on both the reference body motion and the object, and a sampling-based trajectory optimizer (SBTO). Motion refined from our references stays ahead on every metric under both refiners, and by the widest margins on the interaction itself.

Release

Dataset

We release the pipeline together with a dataset of robot HOI clips drawn from five source datasets, intended as reference motion for downstream reinforcement learning. Every clip ships with an automated quality verdict, which 91.4% of them pass; the rest are shipped flagged rather than deleted, with the raw metrics behind the verdict, so the threshold can be re-chosen downstream.
